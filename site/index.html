THE POINT

One address for your callers. Many paths behind it.

01

Fast local debugging

Run the gateway close to your tools, inspect gateway time separately from adapter time, and keep model inference upstream.

02

Routes you can explain

Entries, accounts, model ports and fallback edges stay visible. A simple direct call is just the smallest DAG.

03

Secrets stay behind the daemon

Provider keys never reach the browser, history, screenshots or public docs. Management responses show masked state.

A WORKING CONSOLE

See the shape before you ship the call.

Dashboard telemetry, a left-to-right route graph and side-by-side Playground comparisons keep the important facts near the action.

START IN MINUTES

Keep the client simple.

Point a Jev caller at the gateway, configure provider accounts once, then let the route policy handle reuse and failover.

CURRENT BOUNDARY

v0.3.0 is the current release. The headless CLI is a thin HTTP client; TUI, OpenRouter live credentials, five-page native interaction and multi-hardware shutdown measurements remain explicitly bounded in the release notes. The gateway exposes Jev-native behavior; it does not become a general OpenAI or Anthropic chat gateway.
