# Jev Switch 交互原则

本文约束当前控制台、Tauri 桌面端与 Android WebView 的共用交互。具体页面以运行中的控件语义为准；历史设计草案不覆盖本原则。

## 二值状态切换

可逆的二值按钮使用**固定文案描述非默认状态**，例如“对局域网开放”。熄灭表示关闭，主题色高亮表示开启；文字不随状态改成相反动作，避免用户误把当前状态读成点击后的结果。按钮应提供 `aria-pressed`、可见键盘焦点及禁用/忙碌状态。涉及网络暴露时，首次开启仍先显示说明与确认；关闭可直接执行，失败时恢复真实状态并明确报错。颜色是快速识别，不能替代可访问状态或风险说明。

## 触屏与桌面操作同构

高频选择操作不以 Ctrl/Shift 为必要条件。演练场样例轻点/左键切换多选，至少保留一个；长按/右键快速聚焦为单选，键盘菜单键或 Shift+F10 也可触发。选中态使用主题色和 `aria-pressed`，示例按钮自动换行，不制造横向滚动。

## 查找与渐进披露

设置搜索匹配标题、说明和控件文案。搜索框聚焦时在可见匹配文本中高亮关键词；失焦后仍保留筛选，但移除高亮，使用户能专注于调整设置。状态图、路由图和历史列表优先呈现摘要，详情由选择、悬浮或展开获得；无数据不得伪造状态。
