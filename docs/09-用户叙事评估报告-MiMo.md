## 〇、核心洞察（引自叙事文档）

> **「业务代码不再知道后端的存在」——这才是 "Switch" 这个词的真正含义。**

Jev-Switch 的价值锚点不是"多一个代理"，而是把"上游"这个概念从调用方的代码里**彻底删除**：调用方只认 `localhost:11435` + Jev 协议，选谁、切谁、挂了怎么办，全部收敛进网关配置。

## 二、缺失功能处置（本次三条标记）

### 1. `/openai-compat` 入口 —— ❌ **不做**

- **标记**：DeepSeek 胡扯。Jev 是 Jev 协议生态，不是 OpenAI 的降价平替；为讨好"迁移叙事"引入一整套 `messages → questions → logprobs` 双向翻译层，会把网关的核心（Jev 原生路由）稀释成又一个 LiteLLM。
- **影响**：叙事 4 判为**不服务**，从 backlog 中移除；叙事 1、6、8 中与 openai-compat 相关的部分同步划掉。
- **边界**：若未来出现真实用户带着 OpenAI 负载来要，再单独立项论证，不在 m1 默认路径上。

### 2. `fallback + circuit breaker` 与 `shadow / mirror` —— ⏸ **待讨论**

- **fallback**（叙事 1 的核心）：429/504 时自动切下一个上游 + 熔断短期隔离。牵涉 config 顺序语义、错误分类（可重试 vs 不可重试）、"切换是否对调用方透明"的协议问题。
- **shadow / mirror**（叙事 2、7、10 的核心）：影子流量与并行对比牵涉响应形状（单答 vs 双答）、成本翻倍、结果如何不污染主链路。
- 两者都动 `POST /v1/systemone` 的语义与 Router 架构，**需进一步讨论后再排期**，本报告只标记不裁决。

### 3. 默认端口 `11435` —— ✅ **已先做**

- 叙事文档 6 处硬编码 `localhost:11435`；v0.1.0 默认 `8765` 属叙事期望落空。
- **本次已修订**：Rust 监听端口 + React UI（`api.ts` / `Header` / `TestPanel` / `App`）+ 前瞻设计文档（02 / 04 / 05）全部 `8765 → 11435`；Laya 本地 `18765` 不动；历史快照文档（06、PROGRESS.md）保留原值作为 v0.1.0-mvp 记录。
- 随本报告一并提交推送。
