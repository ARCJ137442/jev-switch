## 人工验收顺序

1. 下载同一 v0.5.0 Release 的 Portable ZIP 和 Standalone EXE，先只运行一个；核对 SHA-256、版本号、七页导航和既有配置/历史恢复。
2. Dashboard 点“启动/停止网关”：验证停止后控制台仍在、模型 API 503、再次启动恢复。按 F11 进出全屏，设置中关闭/恢复底栏。
3. Playground：普通单击样例 A，Shift 单击 B/C，再 Shift 取消；输入 101 和 1000，观察仅警示；切页/刷新后保留。复制动态 curl 并检查 JSON。
4. Routing：拖动/缩放/右键整理，构造分叉图验证节点不重叠；检查线宽不因调用改变，选择取消无黑框残留。
5. Statistics：输入每页 10/50/100，翻页和筛选入口/提供商/日期/事件；矩阵无样本必须是未知色，不得显示健康。
6. Settings：开启“对局域网开放”，等待 5 秒确认；用同一 Wi-Fi 平板访问手机地址；关闭后平板失效、本机仍可用。
7. Android：首次打开应直接到完整 UI 且网关停止；点击首页启停，验证调用、通知、旋转/键盘和后台；再测 LAN 与路由图双指缩放。
8. 用最终候选截图替换官网三张历史图；截图无法用 Tauri MCP 取证时，人工完成后再标记官网图册通过。
