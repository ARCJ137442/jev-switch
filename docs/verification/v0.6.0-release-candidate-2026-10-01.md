## 本轮功能

- 设置：版本化 JSON 导入/导出，显式确认、明文上游 key 警告、schema/DAG/adapter 校验和 `no-store` 敏感响应；构建信息、关于、GitHub 更新检查和“后端”用户文案。
- Routing：服务端 `RouteActivity` 在真实上游调用前后发出 activity ID、精确 DAG edge chain、started/retrying/finished 事件；前端支持并发线体曝光、响应辉光、5 分钟健康色温、超时失败、3 秒辉光衰减和 reduced-motion。
- Routing HUD：两组浮动工具栏支持折叠、悬停/聚焦展开，设置默认开启自动隐藏。
- Android：进程内网关、前台保活 service、常驻通知、通知停止动作、Android 13+ 权限状态、Quick Settings tile 和统一 Dashboard toggle；默认网关关闭、保活通知默认开启。
- 官网：导航、主题/语言、Hero 动作和平台下载卡增加可访问 SVG 图标；桌面亮青蓝仍是默认品牌色来源。
- 性能：React 页面按导航懒加载，首页生产首包从单一 500KB+ 降为约 279KB 主包并拆分各页 chunk。

1. 下载同一 `v0.6.0` Release 的 Portable ZIP、Standalone EXE 和 APK；先核对 Release asset SHA-256 与版本/构建信息。
2. 桌面设置中导出 JSON，确认弹窗明确提示明文 key；在隔离数据目录导入，检查提供商、路由、主题、语言、缩放和 HUD 偏好恢复；确认普通 Provider 页面仍只显示掩码。
3. Routing 页面开启自动隐藏，悬停/Tab 展开 HUD；用 fake/本地请求观察同一条 DAG 的整线曝光、重试、成功/失败辉光和并发计数。
4. Android 安装后检查网关初始关闭；启动后检查通知、通知停止动作、Quick Settings tile、后台/锁屏/旋转/键盘稳定性，停止后确认端口释放。
