# v0.9.0 发布候选核验

日期：2026-10-05

## 发布范围

`v0.9.0` 是一次多模态 SystemOne 兼容 minor 发布。它保持 `model`、`state`、`questions` 和 `answers` 的 Jev 原生形状，同时允许本地或明确兼容的上游承载 `extensions`、`media`、`images` 等扩展字段。

网关默认行为是 local 模式保留未知字段并记录字段名；`strip_unknown_fields = true` 时在 gateway 边界清除它们。TypeSafe provider 通过 `forward_extensions` 控制出站转发；官方远程 TypeSafe 默认关闭，本地 loopback 兼容服务可以显式开启或按 local 默认转发。响应元数据和失败 route trace 只记录字段名及 `preserved`、`forwarded`、`stripped` 等处理状态，不保存图片、音频、视频或 Base64 内容。

## 版本一致性

## 已知边界

- 本版本证明的是协议保存、策略控制、转发和审计元数据，不证明任意多模态模型的识别质量或概率校准。
- 真实 OneJev/LLM2Jev/OpenJev 服务的图像 smoke、资源占用、延迟、校准和安全性仍需在 `jev-decision-lab` 独立验证。
- `media` 内容不会被网关缩放、抽帧、下载或解析；扩展 schema 由目标 provider 负责。
- Standalone、安装器、Android 设备和远端 Release 资产的最终状态，以该 tag 对应的 GitHub Actions 与人工核验记录为准。
