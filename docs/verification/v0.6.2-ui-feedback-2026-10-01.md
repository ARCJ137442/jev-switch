# v0.6.2 用户反馈收口核验

**作者：** GPT-6 Luna xhigh（OpenAI Codex）  
**AI 披露：** 本记录由 AI 协助实现与验证；Tauri 原生窗口、Android 生命周期和真实上游调用仍需维护者人工验收。

## 已实现

- Statistics 热力图使用当前入口、提供商、事件和时间范围筛选结果；按容器宽度在秒/分/时/日之间选最细可容纳粒度。
- 每个热力格使用正方形约束，窄视口不产生水平溢出；页大小输入框随数字内容扩展。
- 统计标题层级压平，移除固定“90 天”文案，保留渐进披露的单格详情与历史列表。
- Routing 订阅独立的 EventBus 游标，从 `since=0` 接收真实 `route_activity` 生命周期事件；不再把调用历史 SQLite 游标用于路由动效。
- 路由线芯固定 2px；请求曝光、响应外扩辉光、近期成功/失败色温分别表达，辉光约 3 秒衰减。
- UI 缩放支持 10%–200%；滑块步长 5%，数字输入支持自定义值并持久化。
- Playground 样例 chip 在窄屏自动换行，保留普通单选、Shift 多选和至少一个样例的约束；移除横向滚动实现。

## 浏览器级证据

- 统计页在窄视口中 `documentElement.scrollWidth === clientWidth`；热力格实测宽高相等。
- 将时间范围从 30 天切换到最近 24 小时后，矩阵切换为按小时并只保留当前范围内的事件。
- 设置数字框输入 `137` 后 `document.documentElement.style.zoom = 1.37`，本地偏好保存为 `1.37`。
- Playground 窄视口样例区域 computed `flex-wrap: wrap`，页面无水平溢出。
- Routing 页面建立 `GET /v1/admin/events/stream?since=0` 连接，避免旧历史游标跳过新 route activity。
