## 建议人工验收顺序

1. 从 Release 下载 Windows Portable 和 Standalone；两个包不要同时运行。先核对版本、SHA-256、窗口大小、顶栏贴边和五页导航。
2. 在 Routing 检查 DAG 全屏画布、拖动/缩放/右键整理、选中连线编辑和真实调用反馈。
3. 在 Providers/Entries 检查搜索自动聚焦、模型目录、可用率条和探测开关；确认关闭自动探测后不再产生后台探测请求。
4. 在 Playground 选择至少两个入口和两个数学题示例，运行一次矩阵，再运行重复测试；切页、刷新、重启后确认历史和选项保留，点开单项确认结构化详情和原始 JSON 仍是次级信息。
5. 在 Settings 切换跟随系统/浅色/深色，检查重启恢复；核对 API 地址和全局设置搜索。
6. 若验收 Android，从 v0.4.1 Release 下载 arm64 experimental APK；允许文件管理器/浏览器“安装未知应用”后侧载。首次打开先确认网关默认关闭；再手动启动网关，核对本机 `/health` 与 Dashboard 状态。随后才测通知/tile/后台/锁屏/旋转；发现问题时开启 Android 调试日志，复现后收集应用私有目录日志，再关闭开关。
