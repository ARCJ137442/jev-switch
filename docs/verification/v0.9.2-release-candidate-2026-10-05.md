# v0.9.2 发布候选核验

日期：2026-10-05

## 变更

- Tauri APP 顶级页面支持 Ctrl+Tab 顺序切换、Ctrl+Shift+Tab 逆序切换。
- 覆盖 Dashboard、Providers、Endpoints、Routing、Playground、Statistics、Settings 七个顶级页面。
- 浏览器环境不接管 Ctrl+Tab；输入框、文本域、选择框和 contenteditable 保持原生编辑行为；只读用户只循环可见页面。
- v0.9.1 的多模态 SystemOne 扩展兼容与 Routing DAG 滚轮平移继续保留。

## 用户叙事与对照

用户在 Jev Switch 中反复比较 Dashboard、Providers、Routing 和 Playground，需要连续查看多个顶级页面。鼠标往返顶栏会打断对照节奏，而普通浏览器的 Ctrl+Tab 又不应被网页版本抢走。现在 Tauri APP 中按 Ctrl+Tab 顺序切换、Ctrl+Shift+Tab 逆序切换；焦点位于输入控件或可编辑区域时快捷键让位。结果是七个顶级页面像浏览器标签一样循环切换，当前页面状态和 hash 路由保持一致。

对照场景是：Tauri APP 接管页面循环，普通浏览器保留浏览器标签切换；输入框保留编辑快捷键，只读用户只循环访问有权限的页面。该功能只改善页面导航效率，不改变页面内部 Tab 焦点顺序、浏览器环境行为或页面权限。

## 边界

快捷键在 Tauri APP 中启用，普通浏览器不接管 Ctrl+Tab；输入控件、可编辑区域、页面权限和页面内部焦点顺序不变。原生 Tauri WebView、不同键盘布局和桌面系统组合键仍需人工抽查。
