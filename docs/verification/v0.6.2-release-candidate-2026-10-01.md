## 变更

- Android keystore 判型读取二进制 magic bytes，PKCS12 和 JKS 各自再用指定 store type 校验密码与 alias；签名时 PKCS12 取 keystore password，JKS 取 key password。
- `scripts/android/test-keystore-type-detection.ps1` 临时生成两种格式密钥并验证判型，测试结束自动删除临时密钥。
- Windows Tauri 启动时显式把 canonical black-and-white J icon 设到主窗口，托盘继续使用同一图标。
- Portable 与 Standalone 打包后提取 EXE 图标并逐像素对比 `src-tauri/icons/icon.ico`；母版哈希、全尺寸 ICO 帧和黑白像素门禁不通过就阻止 Release。
- 单实例身份改为完整 SemVer 精确隔离，避免旧补丁版本驻留托盘时接管新版本启动。
- v0.6.1 Standalone 实际文件哈希为 `41CB25957970E05C9F40B1EBDD702FEE7C7E07C1BDC55265B4D3C214D635976D`；从该 EXE 提取出的图标显示为品牌图。用户截图中的旧图标/旧界面更符合旧托盘进程接管，而非 Release EXE 丢失 ICO 资源。
- `v0.6.2`、`v0.6.3`、`v0.6.4` 曾触发 Android 签名候选 CI，但均未创建 GitHub Release；本次将修复合并到首个成功签名的公开补丁版本 `v0.6.2`，不为失败构建尝试公开递增版本。
