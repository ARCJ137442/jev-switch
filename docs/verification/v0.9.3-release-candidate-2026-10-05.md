## 证据边界

本记录不声称本地已有公开 CA PFX，也不把自签名证书当成 SmartScreen 信誉来源。只有配置仓库 Secrets 后的正式 tag 才会产出签名 Windows Release；新证书仍可能遇到基于下载信誉的 SmartScreen 提示。exomind 本地对照产物经 `Get-AuthenticodeSignature` 验证为 `NotSigned`，因此其运行体验不能作为 Windows 签名证据。

修复路径：在仓库 Actions Secrets 配置 `WINDOWS_CERTIFICATE_BASE64` 与 `WINDOWS_CERTIFICATE_PASSWORD` 后，直接对 [Release run 37285568031](https://github.com/ARCJ137442/jev-switch/actions/runs/37285568031) 选择 **Re-run failed jobs**。不需要移动 `v0.9.3` tag，也不需要重复创建版本号。
