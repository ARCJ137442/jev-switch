## 本地 daemon smoke

使用 `rs/providers.example.toml`、`JEV_SWITCH_MODE=local` 和隔离 `JEV_SWITCH_DATA_DIR` 启动 `jev-switch-daemon v0.3.0`，未调用真实上游。CLI 实际执行：

| 命令 | 结果 |
|---|---|
| `jev-switch-cli --format json status` | health/admin 均返回 `version=0.3.0`、`127.0.0.1:11435`、local |
| `jev-switch-cli models` | 表格列出 5 个公开模型 |
| `jev-switch-cli routes` | 表格列出 10 条路由边 |
| `jev-switch-cli events --since 0 --limit 5` | 返回 `events 0`，持久游标路径可读 |
| `jev-switch-cli --help` | 命令、地址、输出模式和环境变量说明可见 |

daemon 已通过 Ctrl+C 停止，监听端口释放。该 smoke 不证明真实上游调用、cloud 登录会话或 Android 预编译发布；Termux 应按 [CLI 使用文档](../CLI.md) 在设备本机 `cargo install`。
