# 契约 01 · 协议（Jev 内核类型）

> **作者**：Mimo-V2.6-Pro · 2026-09-23 · 状态：**定稿**  
> **crate**：`jev-protocol`（lib，零 IO）  
> **真值基准**：TypeSafe `/v1/systemone` + `jev-life/src/shared/types.ts`  
> **红线**：厂商方言 **不得** 进入本契约类型；方言只活在 adapter DTO。

## 1. 判别值

| 族 | 取值 | 说明 |
|---|---|---|
| 布尔族 | `noul` \| `boolean` | **语义层只有 `noul`**；`boolean` 是 Vercel 方言，只在 `ProtocolAdapter::outgoing` 后出现 |
| 选项 | `choice` | |
| 分数 | `score` | |

对外 `Question.type ∈ {choice, score, noul}`。`boolean` 不作为合法输入判别值（收下也按 `noul` 语义归一，见 §4）。

## 2. 请求

```rust
pub struct JevRequest {
    pub model: String,          // 必填
    pub state: serde_json::Value, // 必填（允许 Null；禁止 serde default 吞掉字段）
    pub questions: BTreeMap<String, Question>, // Record，禁止数组
}
```

## 3. Question（判别联合）

```rust
#[serde(tag = "type", rename_all = "lowercase")]
pub enum Question {
    Choice { instructions: Instructions, criteria: Criteria },
    Score  { instructions: Instructions, criteria: Criteria },
    Noul   { instructions: Instructions, criteria: Option<Criteria> },
}

#[serde(untagged)]
pub enum Instructions {
    Text(String),
    Object(BTreeMap<String, serde_json::Value>),
    Array(Vec<serde_json::Value>),
}

#[serde(untagged)]
pub enum Criteria {
    Map(BTreeMap<String, CriterionValue>),   // choice
    List(Vec<CriterionValue>),               // score 有序档位
    Bool { r#true: CriterionValue, r#false: CriterionValue }, // legacy noul labels
    Raw(serde_json::Value),                  // preserve other optional Noul criteria
}

#[serde(untagged)]
pub enum CriterionValue {
    Text(String),
    Object(BTreeMap<String, serde_json::Value>),
    Array(Vec<serde_json::Value>),
    Null,
}
```

**不变量**
- `instructions` 必填，接受 string/object/array；内部 object/array 内容按 JSON 保留
- Choice `criteria` 必须是 record，值接受 string/object/array/null
- Score `criteria` 必须是有序 array，档位接受 string/object/array
- Noul `criteria` 可省略；提供时必须是 record，并保留其 JSON 原形状

## 4. Answer（判别联合）

```rust
#[serde(tag = "type", rename_all = "lowercase")]
pub enum Answer {
    Choice {
        choice: String,
        probabilities: BTreeMap<String, f64>, // 必填，完整分布
        confidence: f64,                      // 分布集中度，≠ 最高项概率
    },
    Score {
        score: f64,
        legend: Option<serde_json::Value>,         // TypeSafe 标签元数据，保留上游原始 JSON 形状
        probabilities: BTreeMap<String, f64>,
        confidence: f64,
    },
    Noul(NoulAnswer),
}

/// 布尔族：概率本身就是置信度 —— 没有 confidence 字段
#[derive(Serialize, Deserialize)]
pub struct NoulAnswer {
    #[serde(rename = "type")]
    pub kind: NoulKind,                 // "noul" | "boolean"（wire 兼容）
    pub noul: Option<f64>,              // 官方 / OpenRouter 键
    pub probability: Option<f64>,       // Vercel 键 —— 必须保留，禁止吞掉
}
```

**概率读取顺序（冻结）**

```rust
pub fn noul_probability(a: &NoulAnswer) -> f64 {
    a.probability
        .or(a.noul)
        .unwrap_or(0.0)  // 双缺 = 未验到；调用方必须能区分「0.0」与「未知」
}
// 适配层从 boolean 字段兜底时：
//   Some(true) → 0.95，Some(false) → 0.05，仅作最后回退
//   优先级：probability > noul > probabilities["true"] > boolean→{0.95,0.05}
```

## 5. 响应

```rust
pub struct JevResponse {
    pub model: Option<String>,
    pub answers: BTreeMap<String, Answer>,
    pub usage: Option<Usage>,
    pub upstream_calls: Option<u32>,  // 工具循环/重试/多候选实发次数；缺省按 1
    pub latency_ms: Option<u64>,
    pub cost_usd: Option<f64>,        // null ≠ 0：未知就是 null
    #[serde(flatten)]
    pub extra: BTreeMap<String, serde_json::Value>, // providerMetadata 等
}

pub struct Usage {
    pub input_tokens: Option<u64>,
    pub output_tokens: Option<u64>,
    pub reasoning_tokens: Option<u64>,
}
// 反序列化接受驼峰与下划线两套拼写（deny 未知导致的 400 禁止；宽容读入，写出统一 snake_case）
```

## 6. 编解码规则

| 规则 | 要求 |
|---|---|
| tag | `type`，`rename_all = "lowercase"` |
| 未知 `type` | **拒绝**（400），禁止 best-effort 平移到扁平 Option |
| Choice/Score `criteria` 缺失/错容器 | **400**；Noul `criteria` 可省略 |
| 写出 | `Noul` 默认写 `noul` 键；adapter 需要 `boolean`/`probability` 时在 outgoing/incoming 转换 |
| 读入 | 双键并存时都保留（`noul` 与 `probability`） |
| 禁止 | `serde_json::Value` 作为 `criteria`、数值 `score` 或 `usage` 的正式类型；TypeSafe `legend` 是单独保留的 opaque JSON 元数据 |

## 7. 与 jev-life 字段对照（必须一致的项）

| 项 | 本契约 | jev-life | 一致 |
|---|---|---|---|
| Question.type 四方言处理 | 语义 3 + 方言 1 | `NoulType + choice/score` | 是（建模不同、wire 兼容） |
| Choice/Score criteria | 各自必填且按官方容器形状 | 必填 | 是 |
| Noul criteria | 可省略 | 可省略 | 是 |
| Boolean 无 confidence | 是 | 是 | 是 |
| `probability` 与 `noul` 双键 | 是 | 是 | 是 |
| Score.score | `f64` | `number` | 是 |
| Score.legend | 可选 opaque JSON（保留官方字段） | 上游提供时保留，不解释其内部结构 | 是 |
| usage 双拼写 + reasoning | 是 | 是 | 是 |
| upstreamCalls / costUsd=null | 是 | 是 | 是 |
