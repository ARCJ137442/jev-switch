# 契约 06 · 前端与交互

> **作者**：Mimo-V2.6-Pro · 2026-09-23 · 状态：**定稿**  
> **对齐**：Q2 = **先 A+B，稳定后再 C**  
> **强制流程**：设计阶段必须调用 **`/frontend-design`**；视觉与交互向 **CC Switch** 靠。

## 1. 对齐边界

| 层 | 是否靠 CC Switch | 说明 |
|---|---|---|
| 交互范式 | **是（A）** | 卡片、开关、密钥表单、探测按钮、一键启用/停用 |
| 视觉语言 | **是（B）** | 密度/圆角/层级向 CC Switch；Playground 可保留黑白等宽 |
| 配置权威 | **否** | **文件 = 真值源**（Q5）；UI 是编辑器 |
| 桌面形态 | **后续 C** | 前后端测试稳定后 M7 Tauri，再对齐整形态 |

## 2. 信息架构（三页）

| 页 | 内容 | 来源 API |
|---|---|---|
| **Providers** | 提供商卡片列表 + 表单 | `GET/PUT /v1/admin/providers`、`POST …/probe` |
| **Routing** | **模型路由 DAG**；默认编辑器 = **二部图连线题** | `GET/PUT /v1/admin/routes` |
| **Playground** | 现有双栏调试台（微调不推翻） | `POST /v1/systemone`、`GET /v1/models` |

导航含外部修改横幅槽位与全局 toast。

## 3. Providers 页

- **卡片**：名称、kind、base、enabled 开关、`api_key_masked`、最近延迟/最近错误
- **密钥表单**：粘贴新 key → `PUT`；**只显示密文**（掩码/末 4 位）；无「显示原文」按钮
- **Probe**：按钮触发 `POST /v1/admin/providers/{id}/probe`，卡片灯号变色
- **增删**：表单 + 「粘贴 toml 片段」双入口
- **同步**：启动拉 `GET`；`PUT` 后刷新；toml 外部变化 → 横幅「配置已在外部修改」→ **重载**（默认）/ **覆盖**

## 4. Routing 页（模型路由 DAG）

```text
  对外 model id / 别名          提供商
  ┌──────────────┐             ┌──────────────┐
  │ jev          │─────────────│ vercel       │  priority=10
  │              │────────┐    ├──────────────┤
  ├──────────────┤        └────│ laya         │  priority=30
  │ local/*      │─────────────├──────────────┤
  └──────────────┘             │ …            │
```

| 要求 | 说明 |
|---|---|
| 数据模型 | **DAG**（见契约 03）；UI 只是视图 |
| 第一版编辑器 | **二部图连线题**：左列节点、右列提供商、拖线增删边 |
| 线上浮层 | `priority` / `upstream_model` / `sticky` / `on_error` |
| 多跳 | 允许 `right` 指向中间节点；二部图表达吃力时 **升级通用 DAG 视图**（实践条款） |
| 前缀 | `local/*` 以 badge 标注 |
| 双向 | 拖线 → `PUT /v1/admin/routes` → toml；手改 toml → 横幅重载 → 图更新 |
| 环 | 提交前检测，400 时 UI 标红边 |

**渲染**：SVG/Canvas 连线层 + DOM 节点；第一版 **不** 引入重型图编辑器框架。

## 5. Playground 页

- 保留：左 Input（state / questions JSON）+ 右 Output + `Run Jev ↗`
- 微调：Answer 展示按契约 01 分型（Choice/Score/**Noul 无 confidence**）
- Token 显示：优先 `JevResponse.usage`；本地估算必须标「估算」
- 显示 `upstream_calls` / `latency_ms` / `cost_usd`（null 显示 `—` 不显示 0）
