# 契约 04 · 配置与密钥（防偷）

> **作者**：Mimo-V2.6-Pro · 2026-09-23 · 状态：**定稿**  
> **对齐**：Q4=b 本地优先信任开发者；Q5=a 以文件为准；**Q6=防偷强化**（本文件）。

## 1. 默认档（Q4=b）

| 项 | 值 |
|---|---|
| 真值源 | `~/.jev-switch/providers.toml` 或 `JEV_SWITCH_CONFIG` |
| 密钥存放 | **明文** `api_key = "…"` |
| git | `.gitignore` 覆盖 `providers.toml`、`*.enc`、`secrets*` |
| 文件权限 | `providers.toml` **0600**，`~/.jev-switch/` **0700** |
| 哲学 | **本地优先，相信开发者** |

## 2. 防偷红线（与 Q4 不冲突：磁盘可以明文，**暴露面必须密文**）

| # | 红线 | 验收 |
|---|---|---|
| 1 | 上游 API key **只存在于 daemon** | 浏览器 devtools 无明文 |
| 2 | UI **只出密文**：掩码或末 4 位 | `GET` 响应字段名只能是 `api_key_masked` |
| 3 | **无「读回明文」API** | `GET` 单测断言响应体不含配置里的明文 |
| 4 | 日志 / tracing / 错误体 **redact** | 上游 4xx body 可能回显 key，入库前替换 |
| 5 | Playground/调试 **一律 daemon 转发** | 禁止浏览器直连 Vercel/TypeSafe |
| 6 | 密钥真实值不进 AI 上下文、提交信息、截图说明 | 流程约束 |
| 7 | `PUT` 可写入新密钥，响应只回 masked | 无 echo 明文 |

### Redact 约定

- 形态：`sk-****a1b2`（保留类型前缀 3–4 字符 + 末 4）
- 匹配：配置中所有 `api_key` 值；通用模式 `sk-[A-Za-z0-9_-]{8,}`、`Bearer\s+\S+`
- 范围：`ErrorBody`、`tracing`、admin audit、导出的 trace

## 3. 冲突策略（Q5=a）

1. UI 启动读 toml，记录 `mtime + sha256`
2. 保存前重算；不一致 → 横幅 **「配置已在外部修改」**
3. 用户二选一：**重载**（默认，放弃 UI 未保存编辑）/ **覆盖**（用 UI 写回）
4. **禁止**静默丢弃手改

## 4. 升级档（M2+，可配置，非默认）

| 档 | 做法 |
|---|---|
| `secrets.enc` | 口令 → KDF（Argon2id）→ AEAD；独立 `CRYPTO_SECRET` 可选 |
| OS keyring | Tauri/C 阶段对齐 CC Switch；Linux 可用 secret service |
| 集中密钥服务 | 对齐 sub2api：签发 key 给客户端，上游 token 不出边界 |

## 5. 借鉴清单（Phase 0 已调研）

| 来源 | 做法 | 落到 Jev-Switch |
|---|---|---|
| **newAPI** | 上游 channel key 与 **issued key** 分离；`SESSION_SECRET` / `CRYPTO_SECRET` | 未来对外只发派生 key；升级档加密用独立 secret |
| **sub2api** | token 集中保管 + 代理转发 + 权限分层 | daemon 代理边界；admin/ops 分权（后期） |
| **CC Switch** | 本地配置 + 桌面 keyring / 文件权限 | 0600/0700；M7 对齐 keyring |
| 业界 | 无读回明文 API、审计日志、HTTPS | §2 红线 3/4 + 后期 reverse-proxy 指引 |

## 6. 配置 schema（与 `jev-core` 同一份 serde）

```toml
[providers.vercel]
kind = "vercel-gateway"
base = "https://ai-gateway.vercel.sh/v4/ai/evaluation-model"
api_key = "…"              # 0600 文件；UI 只显示 api_key_masked
enabled = true
```
